# 鉤針圈數計數器

純 HTML/CSS/JS 的鉤針圈數計數 PWA，資料存在瀏覽器 localStorage。

- 圈數＋針數雙計數器（加一圈時針數自動歸零）
- 復原、多專案、目標圈數進度條、備註
- 螢幕常亮（Wake Lock）、震動回饋、深色模式、離線可用
- 多分頁同步、要求瀏覽器保留資料（Storage Persist）

鍵盤快捷鍵（電腦）：空白鍵／Enter＝+1 針、R／↑＝+1 圈、Backspace／↓＝−1 針、Ctrl/⌘+Z＝復原。

部署：GitHub Pages → Settings → Pages → Deploy from branch `main` / root。
